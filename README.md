## 🛠️ البنية التقنية (Tech Stack)

### الواجهة الأمامية (Frontend):
- **React.js 19** مع **Vite 8**
- **Tailwind CSS v4** بنظام سمات ألوان نسائية فاخرة (Rose Gold, Deep Plum, Gold)
- **React Router Dom v7** لتوجيه الصفحات
- **Zustand** لإدارة حالة السلة والعملات والتوثيق وحفظها محلياً
- **React Icons** لجميع الأيقونات التفاعلية
- دعم كامل وشامل للاتجاه من اليمين لليسار (**RTL**) والخط العربي **Tajawal**

### الواجهة الخلفية وقاعدة البيانات (Backend & Database):
- **Node.js** و **Express 5**
- **SQLite (better-sqlite3)** بقاعدة بيانات فعلية دائمة ومفهرسة مع وضع WAL السريع
- **JWT (JSON Web Tokens)** و **bcryptjs** لتأمين وحماية لوحة الإدارة
- **Multer + Sharp** لمعالجة الصور وضغطها وتوليد صور مصغرة وتخزينها الدائم
- **Helmet & Rate Limiting** لحماية API ضد الهجمات المتكررة
- حساب الأسعار والإجماليات والتحقق من المخزون من جهة الخادم حصراً

## 🚀 التشغيل السريع محلياً (Local Development)

### 1. تشغيل الخادم الموحد (Production Build):

### 2. تشغيل وضع التطوير المنفصل (Dev Mode):
```bash

cd server
npm run dev

# في نافذة طرفية ثانية: تشغيل الـ Frontend (المنفذ 5173)
cd client
npm run dev
```

## 🌐 النشر على VPS مدفوع من Hetzner (Ubuntu)

### الطريقة الأولى: باستخدام Docker Compose (الموصى بها):
1. انسخي ملفات المشروع إلى السيرفر في المسار `/var/www/makeupi-store`.
2. شغلي الأمر:
```bash
docker-compose up -d --build
```

### الطريقة الثانية: تشغيل مباشر مع Nginx و PM2:
1. ثبّتي Node.js و Nginx و PM2:
```bash
sudo apt update && sudo apt install -y nodejs npm nginx sqlite3
sudo npm install -g pm2
```
2. ابنِ المشروع وشغّليه:
```bash
chmod +x scripts/deploy.sh
./scripts/deploy.sh
```
3. اربطي Nginx:
```bash
sudo cp nginx.conf /etc/nginx/sites-available/makeupi-store
sudo ln -s /etc/nginx/sites-available/makeupi-store /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```
4. فعّلي شهادة SSL المجانية عبر Let's Encrypt:
```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

### النسخ الاحتياطي التلقائي (Cron Job):
أضيفي السطر التالي في `crontab -e` ليتم أخذ نسخة احتياطية يومية في الساعة 3 فجراً:
```bash
0 3 * * * /var/www/makeupi-store/scripts/backup.sh >> /var/log/makeupi-backup.log 2>&1
```

## ✨ المميزات الرئيسية للنظام

1. **الصفحة الرئيسية المتجاوبة:** بنرات متحركة، أقسام الجمال، الأكثر مبيعاً، العروض الخاصة، والماركات الأصلية.
2. **كتالوج وتفاصيل المنتجات:** فلترة حسب القسم، الماركة، السعر، البحث الفوري، خيارات الدرجات والألوان، تكبير الصور، ومنع تجاوز المخزون.
3. **سلة تسوق ذكية:** حفظ المنتجات، تعديل الكميات، حساب المجموع، ودرج منزلق تفاعلي.
4. **نظام إتمام الطلب الشامل:** حساب دقيق لرسوم التوصيل بحسب كل محافظة يمنية، الدفع عند الاستلام، وتوليد أرقام طلبات فريدة مشفرة.
5. **تتبع الطلبات:** صفحة مخصصة للعملاء لمتابعة مراحل الطلب (جديد، مؤكد، قيد التجهيز، خرج للتوصيل، مكتمل).
6. **لوحة تحكم إدارية شاملة:**
   - إحصائيات المبيعات، الطلبات، العملاء، وتنبيهات نفاد المخزون
   - إدارة المنتجات والتصنيفات والعلامات التجارية وإضافة الخيارات
   - إدارة وتحديث حالات الطلبات وحالات الدفع وطباعة الفواتير وتصدير CSV
   - إدارة سعر الصرف (الريال اليمني / الدولار) ورسوم الشحن لكل محافظة يمنية
7. **تكامل واتساب والاتصال بالمطوّر:** زر مباشر لمشاركة المنتجات عبر واتساب، وأيقونات تفاعلية مع Tooltips للتواصل مع المطوّر م. عبدالله المقرمي.
